# 从 MATLAB 坐标到 SolidWorks 叶片实体

## 文件准备

运行主程序，在 `output/` 获得 XYZ 文本；也可使用 `examples/` 的默认数据。每行只有三个数：X、Y、Z，用制表符分隔，无表头、序号或单位字符。坐标数值采用毫米，Z=0。

Excel 文件用于查看，不能直接当作 XYZ 文本导入。历史 IBL 文件含有其他格式的控制行，本仓库不把它们当作 SolidWorks XYZ 文件。

## 推荐流程：四段曲线

1. 在 SolidWorks 新建零件，设置毫米单位，确认所用坐标系与目标平面一致。
2. 选择 **插入 → 曲线 → 通过 XYZ 点的曲线**。浏览选择 `leading_edge.txt`，预览后确认。
3. 依次导入 `pressure_side.txt`、`trailing_edge.txt` 和 `suction_side.txt`，均使用同一个坐标系。
4. 在对应 XY 平面的基准面建立草图。通过 **转换实体引用** 将四条曲线引入同一个草图。
5. 检查连接顺序：前缘 → 叶盆 → 后缘 → 反向叶背。必要时添加端点重合关系，并检查有无重复实体、开口或自交。
6. 测量前缘半径，默认应约为 1 mm。检查整体尺寸，确认没有出现 1000 倍尺度错误；不同版本或单位设置下应以导入后的实测尺寸为准。
7. 草图形成有效闭合轮廓后，使用 **拉伸凸台/基体** 输入所需叶高，得到等截面叶片。叶高由具体设计决定，程序没有给出这个参数。
8. 后续按设计添加轮毂、圆周阵列和装配约束。扭曲、变截面叶片需额外生成多个空间截面，并使用放样或其他建模方式，不能仅靠一次等截面拉伸完成。

## 整条曲线导入

也可尝试一次导入 `blade_profile_xyz.txt`。其首末坐标相同，表达闭合意图。如果软件报告重复点、曲线无效或闭合位置不顺畅，请改用上述四段文件；不要随意删掉最后一点后就把开口轮廓当作闭合轮廓使用。

## 参数变化之后

重新运行 MATLAB 会更新坐标文件。SolidWorks 中通常需要编辑相应曲线并重新加载或重新选择文件，然后重建模型；不是实时双向联动。建议把使用的坐标文件与 CAD 工程一起保存，避免移动文件后失去引用。

## 排查

| 现象 | 检查内容 |
| --- | --- |
| 文件无法读取 | 是否为纯文本、三列数字、无表头；是否误选了 XLSX/IBL |
| 曲线异常跨越或折返 | 点序是否被 Excel 排序；参数是否满足几何约束；有无自交 |
| 不能拉伸 | 是否已转换成同一平面的草图；是否闭合；有无重复或短小实体 |
| 尺度明显异常 | 文档/导入单位与实际测量尺寸 |
| 曲线与期望平面不同 | 导入坐标系、原点及 XY 平面的选择 |

菜单和参考坐标系选项会随版本变化。数据格式与曲线导入入口参考 [SOLIDWORKS 官方：Creating Curves Through XYZ Points](https://help.solidworks.com/2025/English/SolidWorks/sldworks/HIDD_CURVE_IN_FILE.htm)；2025 版本的坐标系与重新加载变化参考 [官方更新说明](https://help.solidworks.com/2025/english/WhatsNew/c_wn2025_parts_curve_xyz_pts_enhance.htm)。本仓库验证了 MATLAB 输出格式，未声称已在 SolidWorks 中完成实体导入测试。
