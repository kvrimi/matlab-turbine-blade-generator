# 几何与数值原理

## 1. 中弧线

A=(0,0)，B=(By·tan α, By)。当前分支选取圆心：

$$O=B+(-R\cos\alpha,\ R\sin\alpha).$$

令 C=O+(R cos β, −R sin β)，D=(Cx+tan β·(Dy−Cy), Dy)。AB、BC、CD 依次连接；圆弧由 B 相对圆心的角度插值到 C 的角度。在上述角度范围和向下延伸条件下，两段直线与中间圆弧的切向一致，但曲率会在直线和圆弧之间发生跃变。

## 2. 半径分布

中弧线共 398 点。控制序号为 `1, round(n_points/3), n_points`，半径为 `r1, rmax, r2`，使用 `interp1(...,'pchip')` 插值。

这里的 r 是构造圆半径，不能直接当作全厚度。三段采用不同采样步长，因此“序号三分之一”不是严格的弧长三分之一，也不是弦长三分之一。调整采样点数会改变厚度分布对应的实际位置。

## 3. 圆族包络

定义圆族隐式方程：

$$F(\mathbf p,s)=\|\mathbf p-\mathbf c(s)\|^2-r(s)^2=0.$$

包络还需满足固定空间点下的偏导条件 $\partial F/\partial s=0$。记 $\mathbf u=(\mathbf p-\mathbf c)/r$，可得 $\mathbf u\cdot\mathbf T=-r'$，再由单位长度条件得到：

$$\mathbf u=-r'\mathbf T\pm\sqrt{1-r'^2}\mathbf N.$$

脚本使用前向/后向/中心差分近似切向和 `dr/ds`。当 `abs(dr/ds)>=1` 时，当前实现停止并要求调整参数，而不是静默截断。满足这个条件也只是局部必要检查，不保证全局没有自交。

前缘圆以 A 为圆心，后缘圆以 D 为圆心，按包络端点角度连接。有限差分和 CAD 样条插值仍然会引入离散误差，“相切包络公式”不等于离散曲线已经证明完美相切。

## 4. 相对原始脚本的整理

- 保留原始 `.m` 的默认参数、中弧线采样和圆族包络方法。
- 原始版本仅移除首行身份信息，放在 `legacy/`；未将其他历史 TXT 代码拼入主程序。
- 主程序用显式圆心公式替代符号方程求解和解序号选择，移除符号工具箱依赖，固定当前左弯分支。
- 拼接轮廓时去除段间连续重复点，保留一个首尾闭合点；因此 500 点抽样的序号与旧版并不完全相同。
- 对不合法的半径变化率报错，避免隐藏几何问题。
- 补充无表头 XYZ TXT、四段导出及图像输出；输出集中在 `output/`。
- 修正“普通三次样条”“完美相切”“转角检查即曲率连续性”等过强或不准确的注释。

这些属于发布整理与 CAD 接口改进，不表示重新完成了涡轮水力优化，也没有复现或验证原研究中的流场、强度及发电性能结论。
